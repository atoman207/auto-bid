# 履歴書AIサポート（Rirekisho AI）

日本での就職を目指すインドネシア人が、スマートフォンで質問に答える（ほぼ選択式）だけで、

1. **日本の履歴書**（一般的な書式）
2. **自己紹介文**（日本語・ひらがな・インドネシア語）
3. **面接でよく聞かれる10の質問と回答例**（日本語・ひらがな・インドネシア語）
4. **模範音声（MP3）**

を作成する Next.js アプリです。生成結果は Google スプレッドシートの履歴書テンプレートに自動で入力されます。利用者の画面には送信完了メッセージだけが表示され、管理者がシート上で確認・修正してから本人に届けます。

---

## 画面とURL

| URL | 内容 |
| --- | --- |
| `/` | サービス紹介（日本語・インドネシア語併記） |
| `/apply` | 入力フォーム（9ステップ・ほぼ選択式・下書き自動保存） |
| `/thanks` | 送信完了 |
| `/listen/{トークン}` | 本人用の学習ページ（本文3言語＋模範音声・速度変更・練習モード・MP3ダウンロード） |
| `/admin` | 管理画面：受付一覧（パスワード保護） |
| `/admin/s/{受付ID}` | 受付詳細：シート・PDF・修正の反映・音声作成・WhatsApp/LINE送信 |
| `/admin/setup` | 初期設定・接続テスト・テスト送信 |

- 公開ページは幅 1200px のコンテナに収め、上部に固定ヘッダーを表示します。
- ヘッダーの **言語タブ（日本語／Indonesia）** で表示言語を切り替えます。同時に2言語は表示しません。初回はブラウザの言語が日本語なら日本語、それ以外はインドネシア語で表示し、選んだ言語はブラウザに保存されます。入力途中で切り替えても入力内容は消えません。
- 学習ページの「ひらがな」「インドネシア語訳」は学習用の本文の表示切り替えで、画面の言語とは別に操作できます。
- 管理画面は日本語のみです。

## 処理の流れ

```
スマホで入力 ──▶ /api/submit ──▶「回答一覧」シートに受付を記録 ──▶ 利用者に完了画面
                                   │（レスポンス後にバックグラウンドで実行）
                                   ▼
                  OpenAI（gpt-4o-mini）で文章を生成（7回の呼び出しを並列）
                                   ▼
            「履歴書テンプレート」をコピー → {{差し込み}} を埋めて個人シートを作成
                                   ▼
   管理者がシートで日本語を修正 → 管理画面「変更を反映して音声を作成」
        → ひらがな・インドネシア語をAIで作り直し → OpenAI TTS で MP3 を作成（Vercel Blob に保存）
                                   ▼
          学習ページのURLを WhatsApp / LINE / メールで本人に送信（ボタン1つで文面作成）
```

## セットアップ

### 1. 必要なもの

- Node.js 20 以上
- OpenAI API キー
- Google アカウント（スプレッドシート用）
- Vercel アカウント（本番公開用）

### 2. Google の設定（サービスアカウント）

1. [Google Cloud Console](https://console.cloud.google.com/) でプロジェクトを作成
2. 「API とサービス」→「ライブラリ」で **Google Sheets API** を有効化
3. 「IAM と管理」→「サービスアカウント」→ 作成（ロールは不要）
4. 作成したサービスアカウント →「鍵」→「鍵を追加」→「JSON」でダウンロード
5. JSON の `client_email` と `private_key` を環境変数に設定（下記）。JSON 全体を `GOOGLE_SERVICE_ACCOUNT_JSON` に貼る方法でも可
6. Google スプレッドシートを新規作成し、右上「共有」で **サービスアカウントのメールアドレスを「編集者」として追加**
7. スプレッドシートのURL `https://docs.google.com/spreadsheets/d/【この部分】/edit` を `GOOGLE_SPREADSHEET_ID` に設定

### 3. 環境変数

`.env.local`（ローカル）に設定します。項目の説明は `.env.example` にあります。

| 変数 | 必須 | 説明 |
| --- | --- | --- |
| `OPENAI_API_KEY` | ✓ | OpenAI API キー |
| `OPENAI_MODEL` | | 文章生成モデル（既定 `gpt-4o-mini`） |
| `OPENAI_TTS_MODEL` / `OPENAI_TTS_VOICE` | | 音声モデル（既定 `gpt-4o-mini-tts`）と声（既定 `coral`） |
| `GOOGLE_SERVICE_ACCOUNT_EMAIL` / `GOOGLE_PRIVATE_KEY` | ✓ | サービスアカウント（または `GOOGLE_SERVICE_ACCOUNT_JSON`） |
| `GOOGLE_SPREADSHEET_ID` | ✓ | 保存先スプレッドシート |
| `ADMIN_PASSWORD` | ✓ | 管理画面のパスワード |
| `APP_SECRET` | ✓ | 署名用の長いランダム文字列（`.env.local` には生成済み） |
| `BLOB_READ_WRITE_TOKEN` | 推奨 | Vercel Blob（MP3の保存先）。Vercel で Blob を接続すると自動設定 |
| `BLOB_ACCESS` | | Blob ストアの種類 `public`（既定）/ `private` |
| `APP_BASE_URL` | 推奨 | 本番URL（学習ページのリンクに使用） |
| `ALLOW_DUPLICATE_SUBMISSIONS` | | `true` で同じ連絡先から何度でも送信可（テスト用。本番は `false`） |

> `GOOGLE_PRIVATE_KEY` は `-----BEGIN PRIVATE KEY-----\n...` のように `\n` を含む1行のまま貼り付けて構いません。

### 4. ローカルで起動

```bash
npm install
npm run dev
```

1. http://localhost:3000/admin/setup を開き、`ADMIN_PASSWORD` でログイン
2. すべての項目に ✓ が付くことを確認
3. 「初期設定を実行」→「回答一覧」「履歴書テンプレート」シートが作成されます
4. 「テスト送信を実行」→ サンプルの回答でAI生成〜シート作成まで動作確認できます

### 5. Vercel にデプロイ

1. このフォルダを GitHub などのリポジトリにプッシュし、Vercel で「Add New Project」からインポート（Framework: Next.js、設定変更不要）
2. Project Settings → **Environment Variables** に上の環境変数を登録（`ALLOW_DUPLICATE_SUBMISSIONS=false`、`APP_BASE_URL=https://本番ドメイン`）
3. **Storage → Create → Blob** でストアを作成し、プロジェクトに接続（`BLOB_READ_WRITE_TOKEN` が自動で追加されます）。Public / Private どちらでも動作します（Private の場合は `BLOB_ACCESS=private`）
4. 再デプロイ後、`https://本番ドメイン/admin/setup` で接続を確認し、テスト送信を実行

> 各APIの処理時間の上限は 60 秒に設定しています（Vercel Hobby / Pro どちらでも動作）。
> Vercel の Hobby プランは個人・非商用向けです。事業として運用する場合は Pro プランをご検討ください。

## 管理者の運用手順

1. **受付一覧**（`/admin`）に新しい受付が表示されます（スプレッドシートの「回答一覧」と同じ内容）
2. 氏名をクリック →「① シートを開く」で、本人用シート（履歴書＋自己紹介文・面接練習）を確認し、**「日本語」の欄を直接修正**します
3. 管理画面に戻り「**② 変更を反映して音声を作成**」を押すと、
   - 修正した項目だけ、ひらがな版・インドネシア語訳をAIで作り直します
   - まだ作っていない模範音声（MP3）を作成します（全21項目：自己紹介文、質問10、回答10）
4. 「履歴書PDF」「面接練習シートPDF」で A4 の PDF をダウンロード（Google にログインした状態で開いてください）
5. 「**③ 本人に送る**」で学習ページのURL入りメッセージが自動で作られます。「WhatsAppで送る」（LINE・メールの場合はそれぞれのボタン）で送信
6. 「対応状況」（未対応／確認・修正中／送付済み）は「回答一覧」シートのプルダウンで管理できます

学習ページは常に**シートの最新の日本語**を表示し、音声も最新の文章に対応したものを再生します（未作成の場合は再生時に自動で作成）。

### うまくいかないとき

| 症状 | 対処 |
| --- | --- |
| ステータスが「エラー」 | 詳細画面にエラー内容が表示されます。原因を直して「AIで生成する」を押してください |
| ステータスが「中断」 | 生成中に時間切れになりました。詳細画面から再生成できます |
| 403 / アクセスが拒否 | スプレッドシートをサービスアカウントに「編集者」で共有してください |
| 音声が作成できない | `BLOB_READ_WRITE_TOKEN` を設定してください（未設定でも学習ページでは再生時に生成されます） |
| 同じ人が再送信したい | 「回答一覧」シートからその人の行を削除すると再送信できます |
| デザインの変更が反映されない | Vercel の Redeploy で「Use existing Build Cache」のチェックを外して再デプロイしてください（ローカルでは `.next` フォルダを削除してからビルド） |

## スプレッドシートの構成

| シート | 内容 |
| --- | --- |
| 回答一覧 | 1受付＝1行。受付ID・日時・生成ステータス・対応状況・連絡先・シートURL・学習ページURL・入力データ(JSON) など。列は見出し名で判別するので並べ替え・列の追加が可能です |
| 履歴書テンプレート | 初期設定で自動作成。1ページ目：日本の一般的な履歴書（JIS様式に準拠）、2ページ目：自己紹介文と面接10問（日本語・ひらがな・インドネシア語） |
| 「氏名 受付ID」 | 受付ごとにテンプレートをコピーして作成される本人用シート |

**テンプレートのカスタマイズ**：フォント・色・罫線・列幅などは自由に変更できます。次の2点だけ守ってください。

- `{{name}}` `{{h1.t}}` などの **差し込み用の文字** を残す（シート作成時に置き換えられます）
- 非表示の **列 I・J**（`intro.ja` `a3.hiragana` などの目印と同期用の値）を消さない。これにより、管理者が行を挿入・移動しても、アプリは正しい行を見つけられます

テンプレートを初期状態に戻すには、初期設定画面の「テンプレートを作り直す」を押します。

## AI 出力の設計

- **3つの版を構造で分離**：OpenAI の Structured Outputs（JSON Schema・strict）で `ja` / `hiragana` / `id` を別々のフィールドとして出力させ、混ざらないようにしています
- **ひらがな版のルール**：日本語版と同じ文・同じ語順、漢字は使わない、カタカナ語はそのまま、数字は読みで書く、文節ごとに半角スペース（分かち書き）
- **品質チェック**：ひらがな版に漢字が残っていたり、インドネシア語訳に日本語の文字が混ざっていたりしたら、その項目だけ自動で作り直します
- **日本語レベルに合わせる**：JLPT のレベル（なし/N5〜N1）に応じて、文の長さ・語彙・敬語の量と、回答の文字数を変えています（本人が理解して話せる日本語）
- **事実を作らない**：入力にない会社名・数字・資格・エピソードを書かないよう指示。短所は改善の努力とセット、お金だけが目的に聞こえる表現は避ける、など面接の定石を組み込み
- **名前の表記ゆれ防止**：最初に氏名のカタカナ表記を決め、すべての文章で同じ表記を使います
- **質問文は固定**：10問の質問（日本語・ひらがな・インドネシア語）はコードに定義済みで、正確です（`src/lib/questions.ts`）
- **プロンプトインジェクション対策**：自由記入欄は区切りタグの中に入れ、指示として扱わないよう明示しています
- 履歴書の学歴・職歴・免許資格・本人希望欄は、選択内容から**AIを使わずに**正確に組み立てます（`src/lib/resume.ts`）

## 開発者向け

```bash
npm run dev     # 開発サーバー
npm run build   # 本番ビルド（型チェックを含む）
npm run lint    # ESLint
```

| パス | 役割 |
| --- | --- |
| `src/app/apply/apply-form.tsx` | 入力フォーム（ステップ・検証・下書き保存） |
| `src/lib/options.ts` | すべての選択肢（日本語・インドネシア語） |
| `src/lib/schema.ts` | 入力の検証（Zod）。クライアントとサーバーで共通 |
| `src/lib/ai.ts` | OpenAI への指示（プロンプト）と JSON Schema、品質チェック |
| `src/lib/resume.ts` | 履歴書の各欄の組み立て |
| `src/lib/sheet-template.ts` | 履歴書テンプレートのレイアウト |
| `src/lib/sheets.ts` | スプレッドシートの読み書き |
| `src/lib/pipeline.ts` | 受付→AI生成→シート作成の流れ |
| `src/lib/tts.ts` | 模範音声の生成と保存（Vercel Blob） |
| `src/app/api/listen/[token]/audio/[key]/route.ts` | 学習ページ用の音声配信（Range 対応で iPhone でも再生可） |
| `src/proxy.ts` | 管理画面・管理APIの保護 |

技術スタック：Next.js 16（App Router / Cache Components）、React 19、Tailwind CSS 4、Zod 4、OpenAI SDK、Google Sheets API（`@googleapis/sheets`）、Vercel Blob。

### セキュリティ

- 管理画面・管理APIは `ADMIN_PASSWORD` によるログインが必要（署名付き HttpOnly Cookie、試行回数制限あり）
- 学習ページのURLは `APP_SECRET` による署名付きで、推測できません（`APP_SECRET` を変更すると配布済みURLは無効になります）
- 入力値はサーバー側でも検証し、スプレッドシートには「そのままの文字列」（RAW）で書き込むため、数式として実行されることはありません
- 送信フォームにはボット対策（ハニーポット）と送信回数制限があります
